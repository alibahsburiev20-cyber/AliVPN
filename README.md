# AliVPN v0.1

Первый телефонный прототип агрегатора публичных VPN-конфигураций.

## Что уже работает
- Android-приложение с экраном CONNECT.
- Загрузка публичного списка конфигураций.
- Подсчёт полученных строк конфигураций.
- Системный запрос разрешения на VPN.
- Создание Android VPN-интерфейса через `VpnService` без захвата всего трафика на этом этапе.
- Сборка APK через GitHub Actions без ПК.

## Что пока НЕ сделано
Этот v0.1 ещё не подключает выбранную VLESS/VMess/Trojan-конфигурацию к полноценному прокси-ядру. Поэтому это именно технический прототип VPN-интерфейса, а не готовый сервис с маршрутизацией всего интернет-трафика через публичный узел.

## Источник списка
https://raw.githubusercontent.com/aviamastersgh/vpn-free-russia/main/verified_configs.txt

Публичные узлы являются сторонними. Не вводи пароли, банковские данные и другую чувствительную информацию через непроверенные узлы.
